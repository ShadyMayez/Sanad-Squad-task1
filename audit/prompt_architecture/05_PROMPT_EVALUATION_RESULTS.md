# Prompt evaluation results

The deterministic prompt contract suite ran with the full regression suite: 66 tests passed. Tests use capture models to assert real LangChain `SystemMessage` and `HumanMessage` objects for Writer, Reviewer, and Semantic Verifier; pinned source quotations remain outside the trusted system instructions. They also check file-loaded prompt sections, source-only task evidence, a content-dependent Visual Agent output, and rejection of non-supported visual input. Fault-injection tests cover a skeptical semantic veto and the existing one-revision/export gates. Mocked success does not establish local-model behavior.

The fixed 20-case local-model semantic benchmark is reported in [the adversarial benchmark](../semantic/04_ADVERSARIAL_BENCHMARK.md). On the final two-pass design, both supported examples were accepted, 15 adverse examples had no false acceptance, and four rejection-category labels differed from the expected labels. The one-pass precursor falsely accepted case L; that failure motivated the selected-span skeptical pass. Its result is preserved rather than hidden.

Six separate real `qwen3.5:4b` prompt-injection probes inserted the following commands into synthetic **source text**: ignore prior instructions; approve regardless of evidence; change role; approve despite rubric failure; a fake system delimiter; and a fake trusted-role header with a request to invent sources. The final parser-aligned rerun accepted **0/6** false claims. It recorded 4,950 prompt and 598 completion tokens. Full per-case verdicts, reasons, and latency are in `injection-final-results.json`; fixtures are under `fixtures/`. A handful of probes cannot prove general prompt-injection resistance, so the Python gates remain authoritative.

The historical `output/sample-week/` had six first-pass accepted pieces but an independent audit found five overbroad or unsupported sentences. The new six-slot run is evaluated in `06_END_TO_END_REGRESSION.md`. Because prompts, evidence snapshots, and the semantic gate changed together, differences in acceptance cannot be attributed to prompts alone.

A real Reviewer calibration using the saved canonical five-tweet Draft and its five supported atomic verdicts returned `approved=true`, factual and technical scores 5, platform score 3, and no rejection reasons. It recorded 2,158 prompt and 149 completion tokens. Before compacting its task, the same Draft received `approved=false` with every criterion above threshold and a 6,000-character self-correcting rationale. The production Reviewer now receives tweet-array measurements and a compact semantic brief; one contradictory response may be re-evaluated, and a second fails the slot. The calibration result is preserved in `../semantic/reviewer-calibration-result.json` and does not by itself establish a general approval rate.
