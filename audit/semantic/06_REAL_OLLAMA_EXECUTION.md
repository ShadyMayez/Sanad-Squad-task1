# Real local Ollama execution

Environment: Python 3.12.13, Ollama server 0.40.3 (CLI client 0.24.0), installed `qwen3.5:4b` model ID `c46e961bbacc`, LangChain 1.4.6, LangGraph 1.2.15, and `langchain-ollama` 1.1.0. The model responded through the local `ChatOllama` structured-output path; the semantic benchmark and injection probes recorded actual Ollama usage metadata. No cloud model was used.

## Diagnostic technical piece

Command: `.venv/bin/python run_piece.py --type tech-thread --topic reentrancy --output output/semantic-final-piece`. This genuine run finished with **0 shipped, 1 dropped, 0 failed**, exit 1, application elapsed **314.229 seconds**, 40,015 recorded prompt tokens and 5,353 completion tokens, complete usage metadata, and peak one active Ollama call. External model API charge was USD 0; electricity and hardware were not measured. Both permitted drafts and reviews are preserved. The first had seven tweets; the second had six. No visual spec or CSV row was exported.

The run correctly rejected claims about an unstated lock mechanism, definitive outcomes from a source saying “may,” an unsupported `root cause` formulation, and version effects absent from the quote. It also exposed false rejections: the skeptical pass sometimes required each selected span to prove a conjunction alone, even when the spans jointly covered actor and timing. The Reviewer suggested reversing a negation about external control, a correction the semantic gate did not allow to ship. In response, the skeptical instruction now explicitly evaluates selected spans jointly; the Writer and Reviewer task JSON omit legacy KB `description`, `root_cause`, and `excerpt` summaries; and the Writer prompt demands close paraphrases and no invented causal labels. An incomplete SWC-107 quotation was extended to its complete sentence already in the pinned snapshot. These changes are separately tested and the fixed benchmark is rerun; the diagnostic run is retained unchanged.
