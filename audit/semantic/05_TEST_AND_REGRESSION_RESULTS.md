# Semantic controls and regression tests

Command: `.venv/bin/python -m pytest -q` after the selected-span skeptical audit and source-authority correction. Result: **68 passed in 1.49 seconds**. Pytest is configured to collect `tests/` and `audit/tests/`; the preserved historical audit snapshot is excluded from duplicate collection.

The tests verify pinned source hash, exact quote and offsets, missing snapshot and path escape handling; abbreviation and Markdown-bullet boundaries; atomic sentence and clause coverage with quantifiers, negation, numbers, and conditions; unknown evidence rejection; fake model selection of real source spans only; malformed output; independent skeptical veto; and source disappearance and malformed pinned evidence failing only their selected slot, plus verifier timeout failing without consuming a content revision. Export refuses a forged quote, span option ID, or mismatched final claim ID before creating a run folder. Prompt contract tests assert real LangChain message roles, dynamic evidence outside system instructions, file-loaded guidance, one bounded Reviewer consistency repair and fail-closed second contradiction, and a content-aware Visual Agent that refuses non-supported input. A visual-generation fault preserves draft and review history and does not stop another slot.

The original workflow regression covers schema validation, CLI parsing and overrides, registry extension, brand and format hard rules, first-pass acceptance, one revision, second rejection, no forced approval, isolated failures, default model-call limit, deterministic ordering, accepted-only CSV quoting and visual paths, complete JSON exports, and measured usage handling. These are deterministic fixtures with mocked model responses. They prove control flow and output contracts, not real model accuracy.

The fixed 20-case benchmark used actual `qwen3.5:4b` calls for 17 semantic cases. The final version recorded **2/2 supported accepted, 0/15 adverse false accepts, 80% exact five-label accuracy**, with four safe rejection-category disagreements. Six separate live prompt-injection probes produced **0/6 false accepts**. See `04_ADVERSARIAL_BENCHMARK.md` and the prompt evaluation report for full scope and caveats.
